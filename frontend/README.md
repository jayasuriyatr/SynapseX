# SynapseX frontend

This directory contains the Next.js frontend for SynapseX. It is currently a frontend prototype with mock API responses enabled by default.

For the complete project overview, architecture, setup instructions, route list, API contract, contribution guide, and current implementation status, see the [root README](../README.md).

## Quick start

```bash
npm ci
copy .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). On macOS or Linux, replace `copy` with `cp`.
